# HOW THIS WORKS

Learning a new word does **not** mean learning its Persian translation.

For each vocabulary item, we gradually build:

> **WORD → MEANING → FORM → CONTEXT → COLLOCATION → PATTERN → PREPOSITION → PHRASAL VERB → WORD FORM → PERSONAL USE → ADVANCED CONTROL**

The same vocabulary is therefore revisited at different levels.

# 📊 FINAL VOCABULARY PROGRESSION

| Level | Main Goal | Student Can... |
|---|---|---|
| 🟢 **A2** | Recognition | understand and use the word |
| 🟡 **B1** | Combination | use common collocations |
| 🟠 **B2** | Control | use patterns, prepositions and phrasal verbs |
| 🔵 **C1** | Precision | control word forms, register and collocation |
| 🟣 **C2** | Nuance | choose vocabulary according to meaning and context |
| 🔴 **C3+** | Mastery | control precision, register, idiomaticity and lexical density |

# 🎯 THE VOCABULARY LEARNING MODEL

The student should eventually move from:

> **WORD**

to:

> **WORD + MEANING**

to:

> **WORD + PATTERN**

to:

> **WORD + COLLOCATION**

to:

> **WORD + PREPOSITION**

to:

> **WORD + PHRASAL VERB / CHUNK**

to:

> **WORD + WORD FAMILY**

to:

> **WORD + REGISTER**

to:

> **WORD + NUANCE**

to:

> **WORD + PERSONAL EXPERIENCE**

and finally:

> **WORD → CHOICE → PRECISION → NATURAL USE**

## FINAL PRINCIPLE

> **Don't ask only: “What does this word mean?”**

Ask:

> **What does it mean?**  
> **How is it formed?**  
> **What words go with it?**  
> **What preposition follows it?**  
> **What grammatical pattern does it take?**  
> **Is it formal or informal?**  
> **What is the difference between it and its synonyms?**  
> **Can I use it naturally in my own life?**
